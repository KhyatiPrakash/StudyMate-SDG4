# 📚 StudyMate

StudyMate is a web-based educational platform developed to support **United Nations Sustainable Development Goal (SDG) 4: Quality Education**.

The platform helps students access learning resources, explore career roadmaps, organize study tasks, and improve productivity through a simple and user-friendly interface.

---

## 🌍 SDG Alignment

### SDG 4 – Quality Education

Quality education is essential for personal and professional growth. StudyMate contributes to SDG 4 by providing students with structured learning resources, career guidance, and study planning tools in a single platform.

---

## 🎯 Project Objective

The objective of StudyMate is to provide students with:

- Easy access to learning resources
- Structured career roadmaps
- Study planning and task management
- Better learning organization
- Improved productivity and self-learning

---

## ✨ Features

### 🏠 Home Page
- Modern and responsive landing page
- Easy navigation to all sections

### 📖 Learning Resources
- Curated educational resources
- Categorized learning materials
- Resource search functionality

### 🔍 Resource Search
- Search resources instantly
- Dynamic filtering using JavaScript

### 🛣️ Career Roadmaps
- Web Development Roadmap
- Java Developer Roadmap
- Structured learning paths

### ✅ Study Planner
- Add study tasks
- Mark tasks as completed
- Delete tasks
- Data stored using Local Storage

### 🌙 Dark Mode
- Toggle between Light and Dark themes
- Theme preference saved automatically

### 📩 Contact Page
- Name field
- Email field
- Message textarea
- User-friendly interface
